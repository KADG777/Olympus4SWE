01 · Inputs & Scope

双方输入对照：同为 AI 工程师小红书社区，O4E 承接更重的 5 能力规格

Pure Pi 1.5.2 输入（BlackNote Dev） qwen3.8-flash · medium
「我想开发一个类似小红书的平台, 不过目标用户是AI工程师, 我希望大家能一起在这个平台讨论AI新闻/工具/产品等等」
  • 边界条件（4 条）：Web 图文瀑布流、固定 AI新闻/AI工具/AI产品 3 话题 + 自定义标签、内置邮箱密码 + 预置管理员、服务端重启持久化。
  • 喂入方式：一次性拼入 prompt.md，未要求作者关注流、编辑笔记、SVG 预置图文等进阶能力。
Olympus4SWE 最新输入（run-4e19c8d93539） qwen3.8-flash · main@1b4fc18
「为 AI 工程师打造一个类似小红书的图文社区 Web 应用 BlackNote（Python FastAPI + SQLite + 原生 HTML/CSS/JS，入口 backend/main.py 暴露 app = FastAPI()）。」
  • 5 个独立用户能力：① 账号会话 + 首次启动幂等预置 2 账号与 6 条带内置 SVG 封面图的精选图文笔记；② 发布/编辑/删除（固定 4 话题 #AI新闻/#开源工具/#模型评测/#工程实践）；③ 首页双列瀑布流 + 标签筛选 + 搜索 + 详情；④ 幂等点赞/收藏/评论；⑤ 作者关注关系与关注列表。
  • 技术与验收约束：仅用标准库与已装 FastAPI/SQLite；DATA_DIR 重启持久化；首页浅色暖灰中文小红书风且无 console 报错。
